First Steps:
  • Define endpoints: *adapt to your needs*. The brackets are necessary
    • init: https-post://{your.server}/out/frames/{YourFrameName}
    • frames: https-put://{your.server}/out/frames/{YourFrameName}
    • Check if YourFrameName is not already in use
  • Create Init activity
    • Create a new "Service Call with Script"
    • Set the Endpoint to "init"
    • Set your arguments, e.g., width: 10, height:10, languge: de-at and some title
  • Create Frame activity
    • Create a new "Service Call with Script"
    • Set the Endpoint to "frames"
    • Set your argument Type to "Set UI and contion" (default option)
    • Set your other arguments, e.g., displacement left:0, top:0, width:10, height:10
    • In section "Page URL" click on the button "New Page/Language"
    • Define the URL that should be displayed
    • Add parameters, that are sent to the displayed page. You have to include https://cpee.org/out/frames/js/frames.js in the displayed HTML. Then you can access cpee.data and cpee.callback
  • Execute your Process
  • Open your frame URL - add (YourFrameName) to the URL currently open in this browser window
Other Steps:
  • My new frame site process runs through once and then its done
    • Use an endless loop within your proces engine
    • Be aware that in case you do not wait for input at some point your loop will run a gazillion times per second!!!
  • Ohhh nooo i forgot the process engine instance that drives my frames application
    • In the case your site is not empty
      • Inspect the site (ctrl+shift+c)
      • Find one of your iframes
      • The attribute "id" contains the callback URL, which contains your instance ID
    • In the case your site is empty
      • You did something wrong
More Helpful Tips:
  • Tip A: My process engine needs to receive something from a frame
    • Create a new task "Service Call with Scripts"
    • Set the endpoint to "frames"
    • Set your argument type to "Set UI and wait for input"
    • Set your other arguments, e.g., displacement left:0, top:0, width:10, height:10
    • In section "Page URL" click on the button "New Page/Language"
    • Define the URL that should be displayed
    • Set the Finalize to: "data.yourDataElementName = result"
    • How to return data from your frame? See Tip B below
  • Tip B: My Frame needs to return something to the process engine
    • You have some fancy HTML site that wants to send oodles of data back to your cpee
    • Include https://cpee.org/out/frames/js/frames.js in your fancy HTML
    • Within your fancy HTML call the javascript function cpee_callback(cpee.callback,yourJsonDataHere)
    • All you need to change is define "yourJsonDataHere"
  • Tip C: I want to delete some frames
    • Create a new task "Service Call with Script"
    • Set the endpoint to "frames"
    • Set your argument type to "Set UI and continue" (default option)
    • Set your other arguments, e.g., displacement left:0, top:0, width:10, height:10 to match the frames you would like to delete
    • Execute
  • Tip D: I want to access the data that i sent to my fancy HTML
    • You have some fancy HTML site that serves as a template and wants to display oodles of data sent from the cpee
    • Include https://cpee.org/out/frames/js/frames.js in your fancy HTML
    • Access the data with cpee.data. Its JSON
